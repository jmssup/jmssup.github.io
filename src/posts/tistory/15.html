트리

일반적인 트리(General Tree) 는 나무를 거꾸로 세워놓은 형태의 자료구조이다.

HTML과 XML의 문서트리, 자바 클래스 계층구조, 운영체제의 파일시스템, 탐색트리, 이항 힙, 피보나치 힙과 같은 우선순위 큐가 트리 구조이다.

 

용어

루트(root): 트리의 최상위에 있는 노드

자식(Child):  어떤 노드로부터 직접 연결된 하위 노드

차수(Degree): 자식 수

부모(Parent):  자식 노드를 가지는 상위 노드

이파리/잎(Leaf): 자식이 없는 노드

형제(Sibling): 동일한 부모를 가지는 노드

조상(Ancestor): 루트까지의 경로상에 있는 노드

후손(Descendant): 노드 아래로 매달린 모든 노드들의 집합

서브트리(Subtree): 노드 자신과 후손으로 구성된 트리

레벨(Level): 루트는 레벨 1, 아래 층으로 내려가며 레벨 1씩 증가 / 레벨은 깊이(Depth)와 동일한 용어

높이(Height): 트리의 최대 레벨

키(Key): 탐색에 사용되는 노드에 저장된 정보

 

이파리/잎 은 단말(Terminal) 노드 또는 외부(Exteranl) 노드라고도 불린다.

이파리/잎 이 아닌 노드들은 내부(Internal)노드 또는 비 단말(Non-Terminal)노드 라고도 불린다.

 

일반적인 트리를 메모리에 저장하려면 각 노드에 키와 자식 수만큼의 레퍼런스(주소)를 저장해야한다.

최대 차수가 클수록 메모리의 낭비가 심해지고 트리를 탐색하는 과정에서 null인 레퍼런스를 확인하는 과정이 생기기에 매우 비효율적인 탐색과정이 이뤄진다.

 

ordered Tree: 자식의 순서가 정해져있는 트리 / List, Array

unordered Tree: 자식의 순서가 상관없는 트리 / Map, Set

 

Left Child-Right Sibling 표현

기존의 트리 노드들을 left는 자식을 right는 형제를 가리키는 두개의 레퍼런스만 가지도록 하여 같은 구조를 가지지만 레퍼런스 수는 2개로 즉, 이진트리로 표현하는 것이다.

 

이진 트리

각 노드의 자식 수가 2 이하인 트리이다.

각 노드는 필드에 Key, Left, Right를 가지고 있다.

데이터의 위계관계 (부모 자식 관계) 를 표현하기 좋다. (자식의 수가 2 이기에 보기 편하다.)

효율적인 삽입과 탐색이 가능하다.

 

레벨 k에 있는 최대 노드 수는 2^(k-1) 이다.

높이가 h인 포화 이진 트리에 있는 노드 수는 2^(h-1) 이다.

높이가 h인 완전 이진 트리에 존재할 수 있는 노드 수 n 은 2^(h-1) <= n <= 2^h - 1 이다.

n개의 노드를 가진 완전 이진 트리의 높이는 밑이 2인 log(n+1) 이다.

 

특별한 형태의 이진트리

포화 이진 트리(Perfect/Full Binary Tree): 각 내부 노드가 2개의 자식을 가지고 모든 잎이 같은 층에 있는 트리 (완전 삼각형 모양)

완전 이진 트리(Complete Binary Tree): 마지막 레벨을 제외한 각 레벨이 노드들로 꽉 차있고, 마지막 레벨에는 노드들이 왼쪽부터 빠짐없이 채워진 트리 (삼각형에 오른쪽 맨 아래가 파먹힌 모양)  

 

 

이진 트리의 연산

이진 트리에서 수행되는 기본 연산들은 트리를 순회(Traversal)하며 이루어진다.

이진 트리는 전위 순회, 중위 순회, 후위 순회, 레벨 순회가 있다.

전위, 중위, 후위 순회는 모든 루트로부터 동일한 순서로 노드들을 지나가는데, 특정 노드에 도착했을 때 그 노드를 방문할지 아니면 지나치고 나중에 방문하는지에 따라 구분된다.

 

1. 전위 순회

전위 순회는 노드에 도착하면 바로 방문한다.

노드의 왼쪽 자식 즉, 왼쪽 서브트리를 먼저 전부 방문하고 이후 오른쪽 서브트리를 모두 방문한다.

 

2. 중위 순회

중위 순회는 노드에 도착하면 방문을 미루고 왼쪽 서브트리로 순회를 진행한다.

왼쪽 서브트리의 모든 노드를 방문한 이후에 도착한 노드를 방문하고 오른쪽 서브트리도 같은 방식으로 방문한다.

 

3. 후위 순회

후위 순회는 노드에 도착하면 노드의 방문을 보류하고 왼쪽 서브트리를 방문한다.

이후 오른쪽 서브트리도 방문한 이후에 해당 노드를 방문한다. 

4. 레벨 순회 

레벨 순회는 루트가 있는 최사우이 레벨부터 시작하여 레벨마다 좌에서 우로 노드를 방문한다.

너비 우선 탐색이라고 볼 수 있다.

 

 

size 연산: 트리의 노드 수 = 1 + 루트의 왼쪽 서브트리 노드 수 + 오른쪽 서브트리 노드 수

height 연산: 1 + 왼쪽 혹은 오른쪽 서브트리중 더 큰 높이값

isEqual 연산: 왼쪽 서브트리와 오른쪽 서브트리를 각각 전위 순회 시켜서 서로 다른 점이 발견 되면 false를 반환 끝까지 순회하면 true를 반환

 

앞서 설명된 각 연산들은 노드를 한 번씩만 방문하기에 O(n)의 시간복잡도를 가진다.
