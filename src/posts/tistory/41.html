고급 언어인 Java, C, Python 등을 이용하여 프로그램을 작성하면 이 코드들은 사람이 해석하기 쉽도록 짜여진 것이다.

컴퓨터의 관점에서는 0과 1밖에 모르기에 문자로 이루어진 일에 대하여 제대로 해석하지 못한다.

그래서 Java, C, Python 등을 이용하여 코드를 작성하면 이를 컴파일러가 어셈블리 프로그램으로 번역하고 이후 어셈블리에서 기계어로 번역하는 과정이 이뤄진다.

그렇다면 이 기계어를 컴퓨터는 어떻게 해석하고 받아들이는지 컴퓨터 구조에 대하여 알아보겠다.

 

컴퓨터 구조란

컴퓨터 시스템의 하드웨어(물리적 부품)와 소프트웨어(명령 집합)가 어떤 방식으로 설계되고 동작하는지, 즉 컴퓨터가 작업을 수행하는 원리를 체계적으로 다루는 학문으로  CPU, 메모리, 입출력 장치 등 각 구성 요소의 역할과 이들이 어떻게 상호작용하여 효율적으로 데이터를 처리하는지에 중점을 둔다.

 

컴퓨터 관점에서의 성능(효율)이란

기본적으로 컴퓨터의 성능이 좋다라는 것은 속도와 안정성을 의미한다. 하지만 컴퓨터 내부적으로는 많은 장치들이 서로 연결되어 상호작용하며 동작한다. 또한 이 장치들은 용도, 능력이 크게 다른 장치들도 있지만 비슷한 장치들도 존재한다.

그래서 이 장치들에 대한 능력비교는 특정 성능에 대한 비교를 비율로 계산하여 판단한다. 

 

현대 컴퓨터들은 폰노이만 구조로 이루어져 있다.

폰노이만 구조는 컴퓨터를 CPU, 메모리, 입출력 장치, 버스 로 구성되어 있다.

 

 

 

 

현대 컴퓨터 구조의 4대 핵심 요소와 주요 역할

CPU (중앙처리장치) 모든 연산과 제어의 중심. 명령어 해석, 연산, 제어 신호 생성, 프로그램 실행
메모리 프로그램, 데이터 임시 저장. CPU와 신속하게 데이터 교환
입출력 장치 외부 환경과 데이터 교환(키보드, 모니터, 디스크 등)
시스템 버스 CPU, 메모리, 입출력 장치 사이의 데이터·명령 교환 통로

 

1. 중앙처리장치(CPU)

  • 주요 부품: 산술논리연산장치(ALU), 제어장치(CU), 레지스터, 캐시 등
  • 기능: 명령어 해석 및 실행, 프로그램 제어, 데이터 연산

2. 메모리 계층

  • 주기억장치(RAM): 실행 중 프로그램과 데이터를 임시 저장 (휘발성)
  • 보조기억장치(SSD, HDD 등): 데이터 영구 저장
  • 캐시 메모리: CPU와 RAM 사이의 속도 차이를 줄여 성능 향상

3. 입출력 시스템(I/O)

  • 종류: 키보드, 마우스, 프린터, 디스크, 네트워크 등
  • 기능: 컴퓨터 외부와 데이터 송수신, 다양한 입출력 제어 방식 제공

4. 시스템 버스

  • 유형: 데이터 버스, 주소 버스, 제어 버스
  • 기능: 해당 구성 요소들 간 신호 및 데이터 이동을 위한 경로 제공

전체 데이터 흐름 개요

  1. 입력장치 → 메모리로 데이터 저장
  2. CPU가 명령어와 데이터를 메모리에서 읽음
  3. CPU에서 연산·명령 실행 후 출력 또는 재저장
  4. 시스템 버스를 통해 이러한 요소들이 긴밀히 연결되어 동작

 

이렇게 이뤄진 장치들이 물리적으로 연결된 것을 컴퓨터 조직이라고 얘기한다.
