완전 탐색에 주로 사용되는 재귀함수 알고리즘

 

 

재귀함수의 호출 및 종료를 이용하는 알고리즘이다.

for문으로 만들기 어렵거나 불가능한 순열 및 조합을 만들어내기 쉽다.

ex) {1,1,1,1,1}, {1,1,1,1,2}, {1,1,1,1,3} ... 

 

예시 알고리즘

def backtrack(상태):
    if 종료조건:
        결과 처리
        return

    for 다음 상태 in 가능한 선택지:
        if 유망한 선택지인지 검사:
            상태 업데이트
            backtrack(업데이트된 상태)
            상태 원복

 

대표적으로

조합, 순열 문제

N-Queens 문제

미로 찾기

부분집합 문제

탐색 문제에서 조건에 맞는 경로를 찾는 경우

이 경우 백트래킹 알고리즘이 사용된다.
