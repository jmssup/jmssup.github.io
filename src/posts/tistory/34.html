값의 실제 크기가 아닌 값의 상대적 순서가 중요한 경우에 사용되는 테크닉이다. 

 

좌표압축이 필요한 상황

  • 입력 값의 범위가 매우 넓을 때 (예: 1 ≤ x ≤ 10^9)
  • 값의 대소 관계만 중요할 때 (예: 정렬, 구간 쿼리, 세그먼트 트리 등)
  • 메모리 절약, 탐색/정렬/트리 등의 연산 효율성을 높이고 싶을 때

 

좌표압축의 핵심 과정

  1. 정렬
    • 입력된 값(좌표 등)을 오름차순으로 정렬합니다.
  2. 중복 제거
    • 동일한 값이 여러 번 있으면 한 번만 남깁니다.
  3. 순위(인덱스) 부여
    • 정렬된 배열에서 각 값의 인덱스(=작은 값부터 0, 1, 2, ...)를 압축 값으로 사용합니다.
  4. 원래 값 → 압축 값 변환
    • 원래 배열의 각 값을, 정렬된 배열에서의 인덱스(압축 값)로 변환합니다.

즉, 실제 값이 10억, 100억처럼 커도, 그 값들의 서로 크고 작음만이 필요하면 값을 0, 1, 2, ... 처럼 작은 정수 범위로 바꿔서 문제를 단순화하고 효율을 높일 수 있다.

 

 

예시)

입력된 값이 5, 10, 3, 2, -5

이런식으로 존재한다고 하자.

이 때 좌표압축을 진행하면

-5 → 0

2 → 1

3 → 2

500  → 3

100000 → 4

 

이러한 상태로 순위를 부여하여 기존 값을 상대적으로 작은 크기의 값으로 바꾸는 것이다.
