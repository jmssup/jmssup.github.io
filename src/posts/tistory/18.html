이진 탐색

정렬된 데이터의 중간에 위치한 항목을 기준으로 데이터를 두 부분으로 나누어 가며 특정 항목을 찾는 탐색 방법이다.

 

BST

이진 탐색 트리(Binary Search Tree)

이진 탐색의 개념을 트리 형태의 구조에 접목한 자료구조

 

BST의 각 노드는 Key값이 왼쪽 서브트리의 Key값보다 크고 오른쪽 서브트리의 Key값보다 작다는 조건을 만족한다.

BST에서 중위 순회를 진행하면 정렬된 Key값을 얻을 수 있다.

 

BST의 노드는 필드에 Key, Value, Left, Right를 가지고 있다

 

탐색 연산

탐색하는 Key가 k라면 노드의 Key와 k를 비교한다.

만약 k가 Key보다 작으면 노드의 왼쪽 서브트리로 k의 탐색을 이어간다.

만약 k가 Key보다 크면 노드의 오른쪽 서브트리로 k의 탐색을 이어간다.

만약 같다면 탐색 성공이다.

 

삽입 연산

탐색 연산과 유사하게 진행한다.

이미 Key가 존재한다면 Value만 갱신해준다.

Key가 없다면 탐색에서 null을 반환해준 것과 다르게 삽입하려는 값을 가지는 새 노드를 생성해서 부모와 연결한다.

 

최솟값 탐색

최솟값은 루트로부터 왼쪽 자식을 따라 내려가며 null을 만났을 때 null의 부모가 가진 Key값이다.

 

최솟값 삭제

최솟값 노드를 찾고 그 노드의 부모와 오른쪽 자식을 연결한다.

 

삭제 연산

삭제할 노드를 찾고 BST의 조건을 만족하도록 삭제된 노드의 부모와 자식을 연결한다.

 

case 0: 삭제되는 노드가 자식이 없는 경우

삭제될 노드 n의 부모가 n을 가리키던 레퍼런스를 null로 갱신한다.

 

case 1: 자식이 하나인 경우

n이 가지고 있는 자식을 부모와 연결한다.

 

case 2: 자식이 둘인 경우

n의 자리에 중위 순회하면서 n을 방문하기 직전 노드(중위선행자) 또는 직후에 방문되는 노드(중위후속자)를 n의 위치로 이동시켜서 n의 부모와 자식을 연결한다.

 

수행 시간

BST에서 탐색, 삽입, 삭제는 최악의 경우 잎까지 내려가고, 삽입과 삭제는 다시 루트까지 올라온다.

트리를 1층 내려갈 때는 순환호출이 발생하고, 1층 올라갈 때는 갱신하는 연산이 발생한다. 이는 O(1) 시간 걸린다.

각 연산의 수행 시간은 트리의 높이 h 에 비례하기에 O(h) 의 시간복잡도를 가진다.

n개의 노드가 있는 BST의 높이가 가장 낮은 경우는 완전 이진 트리의 형태일 때고 가장 높은 경우는 편향 이진 트리일 때다.

BST의 높이 h는 log n <= h <= n 이다.

 

AVL 트리

AVL 트리는 트리가 한쪽으로 치우치는 것을 방지하여 트리 높이 균형을 유지한다.

Adelson-Velskii와 Landis가 발명하여 이들의 이름을 따서 AVL 트리라고 한다.

 

균형 이진 트리(Balanced Binary Tree): 탐색, 삽입, 삭제 연산의 수행시간이 O(log n) 으로 보장된다.

 

AVL 트리의 핵심은 삽입이나 삭제로 균형이 어긋날 때 회전 연산을 통해 트리의 균형을 유지하는 것이다.

여기서 균형이란 임의의 노드 n에 대하여 n의 왼쪽 서브트리와 오른쪽 서브트리의 높이차이가 1을 넘지않는 것을 의미한다.

 

Rotate 연산

AVL 트리에서 삽입 또는 삭제를 수행할 때 균형을 유지하기 위해 사용된다.

 

기본적으로

1. Rotate Left

2. Rotate Right

연산이 있다.

 

AVL 트리는 이 2가지 연산을 조합한 4가지 회전 연산을 균형유지를 위해 사용한다.

불균형이 발생한 노드 n에 대하여

LL-회전: 왼쪽 자식의 왼쪽 서브트리 때문일 때 Rotate Right를 두 번 사용한다.

RR-회전: 오른쪽 자식의 오른쪽 서브트리 때문일 때 Rotate Left를 두 번 사용한다.

LR-회전: 왼쪽 자식의 오른쪽 서브트리 때문일 때 Rotate Left 이후 Rotate Right를 사용한다.
RL-회전: 오른쪽 자식의 왼쪽 서브트리 때문일 때 Rotate Right 이후 Rotate Left를 사용한다.

 

이 4종류 회전들은 회전 후 트리들의 모양이 모두 같다.

또한 각 회전 연산의 수행시간은 O(1) 으로 같다.

 

삽입 연산

BST와 동일하게 새 노드를 삽입한다.

새 노드를 삽입하고 루트로 거슬러 올라가며 각 노드의 높이 차이를 갱신하고 이 때 불균형이 발생한 노드가 생기면 이 노드를 기준으로 새 노드가 삽입된 위치에 맞춰서 적절한 회전 연산을 수행한다.

 

삭제 연산

BST와 동일하게 연산을 수행한다.

삭제된 노드로부터 루트로 거슬러 올라가며 각 노드의 높이차이를 갱신하고 이 때 불균형이 발생한 노드가 생기면 반대쪽에 삽입이 이루어져 불균형이 발생한 것으로 취급하여 적절한 회전 연산을 수행한다.

 

삽입과 삭제 모두 회전 연산 수행 후에 부모에서 불균형이 발생할 수 있다.

이런 일은 반복적으로 생겨 루트에서 회전 연산을 수행해야 하는 경우도 생긴다.

 

수행 시간

AVL 트리에서의 탐색, 삽입, 삭제는 공통적으로 루트부터 탐색을 시작해 최악의 경우 잎까지 내려간다.

이후 삽입 및 삭제는 다시 루트까지 거슬로 올라가야 한다.

 

트리를 1층 내려갈 때는 순환 호출하며 1층 올라갈 때 불균형이 발생하면 적절한 회전연산을 수행한다. 이는 O(1) 이다.

탐색, 삽입, 삭제 연산의 수행시간은 각각 AVL 트리의 높이에 비례한다.

높이 h 는 노드 수 n 일 때 log n 이기에 각각의 연산의 시간복잡도는 O(log n) 이다.
