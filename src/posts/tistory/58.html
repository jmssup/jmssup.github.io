계획:

웹 기초지식 이어서 학습: 웹 브라우저, 쿠키 등 

HTML로 웹 페이지 만들어보기 

Flask로 웹 서버 코딩

결과:

이번 주차에서는 저번주에 이서 웹에 대한 기초 지식을 늘려갔다. 저번주에 HTTP에 관한 내용을 중점으로 배웠다면 이번 주에는 웹 브라우저와 개발자 도구, 쿠키, 세션, SOP에 관한 내용을 중점으로 학습하였다. 들어본 개념도 있고 처음 듣는 개념도 있는데 웹 브라우저같은 경우는 원래 알던 것에서 조금 더 추가된 정보를 얻고 브라우저에 대한 개념을 단단하게 다지는 시간이 되었고, 개발자 도구를 활용하는 방법을 배우는 과정이 굉장히 재밌었다. 특히 쿠키와 세션에 관한 개념을 자세하게 익히고 개발자 도구를 이번에 해결한 워게임에서 적극적으로 활용하여 쿠키와 세션을 바꾸면서 권한을 얻는 식으로 푸니까 진짜 해킹을 한 것 같은 느낌이 들어서 좋았던 것 같다. 해킹에 대해 더욱 관심을 많이 가지게 되는 내용이라는 생각이 든다. HTML과 Flask를 통해 웹을 만들어 봐야 되는데 웹 개념을 배우고 관련 워게임 3개를 푸니까 생각보다 시간이 많이 흘러서 시간안에 하지 못했다.

HTML과 Flask는 개강전에 익히고 가면 좋을 것 같으니까 다음주 평일 중으로 다 학습하는 것을 추가 목표로 잡겠다.

결과:
