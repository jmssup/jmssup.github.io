정렬된 데이터를 순서대로 훑으면서 문제를 해결하는 기법들을 통틀어서 스위핑이라고 칭한다.

스위핑은 정렬된 데이터를 한 번만 탐색하는게 특징이자 핵심이다.

 

스위핑의 핵심 토대

  • 정렬: 먼저, 구간의 시작점/끝점, 이벤트 좌표 등 문제의 핵심이 되는 값들을 정렬한다.
  • 단방향 순회: 정렬된 데이터를 한 번만(왼→오른쪽 또는 아래→위 등) 순회한다.
  • 상태 갱신: 순회 중에 현재 겹치는 구간 수, 활성화된 이벤트, 누적 합 등 문제에 맞는 상태를 실시간으로 갱신한다.
  • 최적해 도출: 각 시점(이벤트 포인트)에서 필요한 최적의 값을 판단한다.

 

스위핑은 보통 DP로 메모이제이션하기에 너무 많은 경우의 수가 존재하는 겹치는 선분, 구간을 찾는 문제에서 주로 사용된다.

 

보통 시작점과 끝점을 이벤트로 보고 정렬시킨뒤 문제 상황에 맞춰 정보를 관리한다.

 

예시 코드) 가장 많이 겹치는 선분에 대한 탐색

ArrayList<Integer> line = new ArrayList<>();
HashSet<Integer> now = new HashSet<>();
for (Event ev : events) {
            if (ev.type == 1) now.add(ev.idx);
            cnt += ev.type;
            if (cnt > max) {
                max = cnt;
                line = new ArrayList<>(now);
            }
            if (ev.type == -1) now.remove(ev.idx);
}

여기서 ev는 좌표값 x, 시작점이라면 type으로 1을 끝점이라면 -1을 저장한다.

 

이러한 방식처럼 단방향으로 상태를 갱신하며 탐색하는 방법이 스위핑이다.
