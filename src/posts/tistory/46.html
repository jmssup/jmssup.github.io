프로그램을 실행하고 데이터를 처리하기 위해서는 정보의 저장이 이뤄져야한다.

컴퓨터는 이 데이터의 저장을 위해 메모리를 이용한다.

 

메모리의 역할은 컴퓨터가 연산에 사용하는 정보, 데이터를 일시적 혹은 영구적으로 저장한다.

이러한 역할이기에 시스템 성능과 직접적으로 연결되어 CPU와 다른 장치 간 데이터 흐름을 효율적으로 관리한다.

메모리 계층 구조 (Memory Hierarchy)

컴퓨터는 속도, 용량, 비용을 최적화하기 위해 여러 종류의 메모리를 계층적으로 사용한다. CPU에서 가까울수록 속도는 빠르지만 용량은 작고 가격이 비싸며 멀어질수록 속도는 느리지만 용량이 크고 저렴하다.

  • 레지스터 (Register): CPU 내부에 있는 가장 작고 빠른 메모리로 CPU가 처리할 데이터를 임시로 저장된다.
  • 캐시 메모리 (Cache Memory): CPU와 주기억장치(RAM) 사이의 속도 차이를 줄이기 위한 고속 메모리이다. CPU가 자주 사용하는 데이터를 미리 저장해두어 시스템 전체의 처리 속도를 높인다. CPU에 더 가까운 순서대로 L1, L2, L3 캐시 등으로 나뉜다.
  • 주기억장치 (Main Memory, RAM): 현재 실행 중인 프로그램과 데이터가 저장되는 공간이다. CPU가 직접 접근하여 데이터를 읽고 쓸 수 있다.
  • 보조기억장치 (Secondary Storage): 하드디스크(HDD), SSD, USB 메모리 등이 해당된다. 전원이 꺼져도 데이터가 사라지지 않는 비휘발성(non-volatile) 메모리로, 운영체제, 프로그램, 사용자 파일 등을 영구적으로 저장하는 역할을 한다.

메모리의 주요 종류

메모리는 데이터를 유지하는 방식과 읽고 쓰는 기능에 따라 다양하게 구분된다.

종류 특징 주요 용도
RAM (Random Access Memory) 휘발성 메모리로, 전원이 차단되면 데이터가 사라짐. 자유롭게 읽고 쓰기가 가능함. 주기억장치, 캐시 메모리
ROM (Read Only Memory) 비휘발성 메모리로, 전원이 꺼져도 데이터가 유지됨. 주로 읽기만 가능함. 컴퓨터의 기본 입출력 시스템(BIOS) 등 펌웨어 저장
DRAM (Dynamic RAM) 주기적으로 재충전해야 데이터가 유지되는 RAM. 집적도가 높아 대용량으로 만들기 용이하여 주기억장치에 주로 사용됨. 데스크톱, 노트북의 메인 메모리

RAM (Random Access Memory)

RAM은 휘발성 메모리로 전원이 꺼지면 데이터가 소멸한다.

컴퓨터가 현재 수행 중인 작업에 필요한 데이터와 프로그램을 일시적으로 저장하는 주기억장치이다.

CPU가 빠르고 원활하게 데이터를 처리할 수 있도록 돕는 핵심 부품이다.

 

RAM의 역할과 중요성

RAM은 컴퓨터의 전반적인 성능과 속도에 직접적인 영향을 미친다.

  • 고속 작업 공간: 하드디스크나 SSD 같은 보조기억장치에 영구 저장된 운영체제(OS)나 프로그램은 실행될 때 RAM으로 복사된다. CPU는 보조기억장치보다 월등히 빠른 RAM에 직접 접근하여 데이터를 읽고 쓰기 때문에 컴퓨터의 작업 처리 속도가 크게 향상된다.
  • 멀티태스킹 성능: RAM의 용량이 클수록 더 많은 프로그램을 동시에 실행하거나 대용량 파일을 원활하게 다룰 수 있다. 이는 책상이 넓을수록 여러 문서와 도구를 한 번에 펼쳐놓고 효율적으로 작업할 수 있는 것과 같은 원리이다.
  • 성능 향상: RAM 용량이 충분하면 CPU가 데이터를 찾기 위해 느린 보조기억장치에 접근하는 횟수가 줄어들어 시스템의 반응성이 높아지고 게임의 프레임 속도(frame rate) 등이 개선될 수 있다.

 

RAM의 종류

RAM은 데이터를 유지하는 방식과 속도에 따라 크게 SRAM과 DRAM으로 나뉜다.

  SRAM (Static RAM) DRAM (Dynamic RAM)
특징 전원이 공급되는 동안 데이터가 유지됨 (재충전 불필요) 주기적으로 데이터를 재충전해야 유지됨
속도 매우 빠름 SRAM보다 느림
가격 고가 저가
집적도 낮음 (용량이 작음) 높음 (대용량으로 제작 용이)
주요 용도 속도가 중요한 캐시 메모리 PC의 주기억장치 (메인 메모리)
  • DRAM: 용량 크고 가격 저렴, 갱신(리프레시) 필요
  • SRAM: 속도가 매우 빠르고 비쌈, 주로 CPU 캐시에 사용
  • SDRAM/DDR: 동기식 동작, DDR1~DDR5까지 진화

RAM은 용량이 클수록 동시에 여러 작업을 효율적으로 처리한다.

 

RAM의 작동 방식

DRAM

DRAM은 1개의 트랜지스터와 1개의 커패시터(1T1C) 구조를 기본 셀(Cell)로 사용하여 데이터를 저장한다.

  • 데이터 저장 (쓰기, Write): 데이터는 커패시터에 전하(Charge)를 채우거나 비우는 방식으로 저장된다.
    1. 특정 셀의 행을 선택하기 위해 워드 라인(Word Line)에 신호를 보내 연결된 트랜지스터를 킨다.
    2. 데이터를 쓰는 통로인 비트 라인(Bit Line)에 높은 전압을 가하면 커패시터에 전하가 충전되어 1이 저장된다.
    3. 반대로 비트 라인에 낮은 전압을 가하면 커패시터의 전하가 방전되어 0이 저장된다.
  • 데이터 읽기 (Read): 커패시터에 저장된 전하량을 확인하여 데이터를 읽는다.
    1. 워드 라인을 활성화하여 트랜지스터를 킨다.
    2. 이때 커패시터에 저장된 전하가 비트 라인으로 흘러나오면서 비트 라인의 전압에 미세한 변화를 일으킨다.
    3. 센스 앰프(Sense Amplifier)라는 증폭기가 미세한 전압 변화를 감지하고 증폭하여 저장된 값이 1인지 0인지를 판별한다.
    4. 이 과정에서 커패시터의 전하가 방전되기에 읽기 동작은 저장된 데이터를 파괴한다(Destructive Read). 따라서 센스 앰프는 데이터를 읽은 직후 즉시 원래 값으로 다시 써주는(Refresh) 동작을 수행한다.
  • 재충전 (Refresh): DRAM의 커패시터에 저장된 전하는 시간이 지나면 자연적으로 누설되어 사라진다. 이 때문에 데이터 손실을 막기 위해 주기적으로 모든 셀의 데이터를 다시 읽고 써주는 재충전(Refresh) 과정이 반드시 필요하다. 바로 이 재충전이 필요하다는 특성에서 '동적(Dynamic)'이라는 이름이 유래됐다.

 

SRAM

SRAM은 래치(Latch) 회로를 기반으로 데이터를 저장하며 일반적으로 6개의 트랜지스터(6T)로 하나의 셀을 구성된다. 전원이 공급되는 동안에는 데이터를 안정적으로 유지하는 정적(Static)인 특성을 가진다.

  • 데이터 저장 (쓰기, Write): SRAM 셀은 서로의 입출력이 맞물린 두 개의 인버터로 구성된 래치(Latch) 회로를 포함된다. 데이터를 쓸 셀의 워드 라인(Word Line)을 활성화하여 외부 비트 라인과 내부 래치를 연결하는 2개의 접근 트랜지스터를 킨다.
    1. 서로 반대 신호를 가진 한 쌍의 비트 라인(BL과 BLB)에 쓰고 싶은 데이터(예: 1을 쓰려면 BL에 High, BLB에 Low)를 강제로 인가한다.
    2. 이 외부 신호가 래치 회로의 기존 상태를 뒤집어 새로운 데이터가 저장된다.
  • 데이터 읽기 (Read): 래치 회로의 상태를 읽어 데이터를 확인한다.
    1. 먼저 한 쌍의 비트 라인(BL과 BLB)을 동일한 전압으로 미리 충전(Precharge)한다.
    2. 워드 라인을 활성화하여 래치와 비트 라인을 연결한다.
    3. 래치 회로의 상태에 따라 한쪽 비트 라인의 전압은 그대로 유지되고 다른 한쪽은 방전되어 전압이 떨어진다. 예를 들어 셀이 1을 저장하고 있다면, BLB의 전압이 낮아진다.
    4. 센스 앰프가 두 비트 라인 사이의 전압 차이를 감지하여 저장된 값을 빠르고 정확하게 읽어낸다.
  • 정적 유지 (Static Hold): SRAM은 래치 회로 자체적으로 안정된 상태를 유지하기에 전원이 공급되는 동안에는 데이터를 재충전할 필요가 없다. 이렇다보니 DRAM보다 훨씬 빠른 속도를 낼 수 있지만 구조가 복잡하고 셀 면적이 커서 집적도가 낮고 가격이 비싸다.

 

ROM (Read Only Memory)

ROM 은 비휘발성 메모리로 전원이 꺼져도 데이터가 남아있다.

Read Only 라는 이름을 보면 알 수 있듯이 이 메모리는 write의 경우 한 번 만 가능하고 이후에는 오직 read만 가능하다.

 

컴퓨터에서의 ROM은 펌웨어(Firmware)가 저장된다. 펌웨어란 하드웨어 장치를 제어하고 구동하는데 필요한 기본적인 소프트웨어이다. 컴퓨터가 올바르게 작동하는 데 필요한 BIOS/UEFI 와 운영 체제 지침 같은 중요한 정보가 저장되어 컴퓨터 부팅 시 하드웨어를 초기화하고 운영체제(OS)를 불러오는 역할을 한다. 이러한 역할을 수행하기에 컴퓨터 시스템에 필수적이다.

 

ROM의 작동 방식

ROM은 메모리 셀이라는 집적 회로를 사용해 작동한다. 이 셀에는 직렬로 연결된 트랜지스터가 포함되어 있어 전원이 공급될 때 전류가 흐를 수 있다. 전류가 이들 트랜지스터를 통과할 때 트랜지스터를 통해 전송되는 다른 신호에 의해 데이터가 지워질 때까지 메모리 셀의 데이터를 저장하는 자기장이 생성된다. 이러한 셀에 저장된 데이터는 컴퓨터 프로세서나 하드 드라이브 컨트롤러와 같은 외부 소스에서 특별히 지시하지 않는 한 변경하거나 삭제할 수 없다.

 

 

ROM의 종류와 발전

'읽기 전용'이라는 이름과 달리, 기술 발전에 따라 데이터를 수정할 수 있는 여러 종류의 ROM이 개발되었다.

  • Mask ROM: 제조 공정에서 데이터가 영구적으로 새겨지는 초기 형태의 ROM입니다. 내용을 절대 변경할 수 없다.
  • PROM (Programmable ROM): 사용자가 전용 장비를 이용해 단 한 번만 데이터를 기록할 수 있는 ROM이다. OTP(One-Time Programmable) ROM이라고도 불린다.
  • EPROM (Erasable Programmable ROM): 자외선을 쬐어 저장된 데이터를 지우고 다시 쓸 수 있는 ROM이다. 데이터를 지우려면 칩을 장치에서 분리해야 하는 번거로움이 있다.
  • EEPROM (Electrically Erasable Programmable ROM): 전기를 이용해 데이터를 지우고 다시 쓸 수 있어 EPROM보다 발전된 형태이다. 장치에 장착된 상태로 펌웨어 업데이트가 가능해졌으며 오늘날 BIOS/UEFI 업데이트에 널리 사용된다.
  • 플래시 메모리 (Flash Memory): EEPROM의 한 종류로 데이터를 블록 단위로 빠르게 지우고 쓸 수 있다. 속도가 빠르고 내구성이 좋아 USB 드라이브, SSD(Solid State Drive), 스마트폰 저장장치 등에서 널리 사용된다. 엄밀히는 ROM의 한 종류지만 쓰기 기능이 자유로워 RAM과 ROM의 경계를 허무는 기술로 평가받는다.
