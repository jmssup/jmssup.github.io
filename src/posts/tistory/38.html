DreamHack 입문 강의 1회독

실습 문제 2개 이상 풀이

결과: 모각코 1회차 결과 : 네이버 블로그

이렇게 해킹에 처음 입문하게 되었는데 처음에는 해킹이라는 단어 자체가 어렵고 멀게 느껴졌지만,

실제로 개념을 배우고 워게임 문제를 하나하나 접하다 보니, 해킹도 결국 시스템을 이해하고 분석하는 과정이라는 걸 느꼈다.

해킹에 대한 간단한 개념, 해킹에 입문하기 위한 기초적인 컴퓨터 과학 기초, 워게임을 진행하는 방법과 실제로 워게임을 진행해보면서 단순한 워게임이어도 코딩문제와는 약간 다른 방식으로 푸니까 익숙하지 않아서 어려웠고 여러 방식과 단계를 거쳐서 문제를 푸는 과정이 헷갈렸지만 문제를 풀었을 때의 성취감은 코딩 문제와는 다른 느낌으로 좋았던 것 같다.

​다음에는 리눅스의 사용법과 웹 해킹과 리버스 엔지니어링에 대한 개념을 자세하게 공부하고 워게임까지 풀어보겠다는 목표를 정했다.

Spring 개발 환경 구축 + REST API 기초

IntelliJ + Maven 프로젝트 설정,

결과:  모각코 1주차 활동 결과(25.07.13) : 네이버 블로그

이번에 Spring과 Spring Boot를 처음 접해보면서, 예상보다 훨씬 복잡하고 생소한 개념이 많아 어려움을 크게 느꼈습니다. 이로 인해 목표와 계획을 조금 하향 조정하게 되었습니다.

의존성 주입, 애노테이션(@RestController, @GetMapping), Maven 설정 등 모두 처음 보는 용어들이라 이론을 따라가는 것도 버거웠고, 실습을 하면서도 왜 이렇게 동작하는지 완전히 이해하기는 쉽지 않았습니다.

앞으로는 모르는 개념들은 서칭과 스프링부트 도서를 더 적극적으로 활용하여 개념을 익혀갈 계획이다.
