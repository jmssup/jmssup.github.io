적절하게 숫자를 정의하기 문제에 대한 풀이

문제 정의

먼저 해결하고자 하는 문제는 다음과 같다.

  • 입력: 길이가 N인 수열 a와 최대 허용 '변경' 횟수인 정수 M이 주어진다.
  • 과정: 1부터 4까지의 숫자로 이루어진 새로운 길이 N의 수열을 생성한다.
  • 규칙 1 (유사도): 새로운 수열의 i번째 원소가 기존 수열 a의 i번째 원소와 같을 때마다 유사도 점수가 1씩 증가한다.
  • 규칙 2 (변경): 새로 생성한 수열에서, 인접한 두 숫자가 서로 다를 경우 '변경'이 1회 발생한 것으로 간주한다.
  • 목표: 총 '변경' 횟수가 M을 초과하지 않는 선에서 얻을 수 있는 최대 유사도를 계산하는 것이다.

DP를 이용한 기본 접근

이 문제의 상태를 정의하기 위해 3차원 DP 테이블을 설정할 수 있다.

dp[i][j][k] = i번째 원소까지 고려했고, 누적 **변경 횟수가 j**이며, i번째에 숫자 k를 배치했을 때 얻을 수 있는 최대의 유사도.

이 DP 테이블을 채우기 위한 점화식은 i-1번째 상태로부터 i번째 상태를 계산하는 방식으로 구성된다. i번째에 숫자 k를 배치하는 선택은 두 가지 경우로 나뉜다.

  1. 변경이 발생하지 않은 경우: i-1번째 숫자 역시 k여야 한다. 따라서 변경 횟수는 j로 동일하며, dp[i-1][j][k] 값에서 상태가 전이된다.
  2. 변경이 발생한 경우: i-1번째 숫자는 k가 아닌 다른 숫자 l이어야 한다. 이 경우 i번째에서 변경이 발생했으므로, i-1번째까지의 변경 횟수는 j-1이었을 것이다. 따라서 dp[i-1][j-1][l] (단, l != k) 값들 중 최댓값에서 상태가 전이된다.

이 점화식을 코드로 구현하면 i (위치), j (변경 횟수), k (현재 숫자), l (이전 숫자)에 대한 4중 반복문이 구성되어, 시간 복잡도는 O(N * M * K²)가 된다. N과 M이 클 경우 이는 비효율적인 접근이다.

병목 현상 분석과 최적화

위 기본 접근법의 성능 저하를 일으키는 주된 원인은 Case 2에서 k가 아닌 모든 l에 대해 dp[i-1][j-1][l]의 최댓값을 구하는 내부 루프다. 이 계산은 매 k마다 반복적으로 수행되므로 상당한 비효율을 초래한다.

이러한 병목을 해결하는 것이 문제의 핵심이며, 이는 마치 시스템 해킹에서 공격 성공을 위해 정확한 offset을 계산하는 과정과 유사하다. 불필요한 연산을 줄이고 핵심적인 값을 빠르게 찾아내야 한다.

이를 위해 접두사/접미사 최댓값 (Prefix/Suffix Max) 배열을 도입할 수 있다. k를 제외한 l에 대한 최댓값은, 1부터 k-1까지의 최댓값과 k+1부터 MAX_K까지의 최댓값 중 더 큰 값과 같다.

  • prefix_max[x]: l이 1부터 x까지일 때 dp[i-1][j-1][l]의 최댓값
  • suffix_max[x]: l이 x부터 MAX_K까지일 때 dp[i-1][j-1][l]의 최댓값

이 두 배열을 미리 O(K) 시간에 계산해두면, k를 제외한 나머지 l에 대한 최댓값을 max(prefix_max[k-1], suffix_max[k+1]) 연산을 통해 O(1) 시간에 조회할 수 있다. 이로써 4중 반복문 구조가 3중으로 개선되고 전체 시간 복잡도는 O(N * M * K)로 크게 향상된다.

최종 최적화 코드

아래는 접두사/접미사 최댓값 기법을 적용하여 최적화를 완료한 코드다.

import sys

MAX_K = 4
INT_MIN = -sys.maxsize

n, m = map(int, sys.stdin.readline().split())
a = [0] + list(map(int, sys.stdin.readline().split()))

dp = [
    [[INT_MIN for _ in range(MAX_K + 1)] for _ in range(m + 1)]
    for _ in range(n + 1)
]

for k in range(1, MAX_K + 1):
    similarity = 1 if a[1] == k else 0
    dp[1][0][k] = similarity

for i in range(2, n + 1):
    for j in range(m + 1):
        prefix_max = [INT_MIN] * (MAX_K + 2)
        suffix_max = [INT_MIN] * (MAX_K + 2)

        if j > 0:
            for l in range(1, MAX_K + 1):
                prefix_max[l] = max(prefix_max[l - 1], dp[i - 1][j - 1][l])
            for l in range(MAX_K, 0, -1):
                suffix_max[l] = max(suffix_max[l + 1], dp[i - 1][j - 1][l])

        for k in range(1, MAX_K + 1):
            similarity = 1 if a[i] == k else 0

            val1 = INT_MIN
            if dp[i - 1][j][k] != INT_MIN:
                val1 = dp[i - 1][j][k] + similarity

            val2 = INT_MIN
            if j > 0:
                max_prev_val = max(prefix_max[k - 1], suffix_max[k + 1])
                if max_prev_val != INT_MIN:
                    val2 = max_prev_val + similarity
            
            dp[i][j][k] = max(val1, val2)

ans = 0
for j in range(m + 1):
    for k in range(1, MAX_K + 1):
        ans = max(ans, dp[n][j][k])

print(ans)
