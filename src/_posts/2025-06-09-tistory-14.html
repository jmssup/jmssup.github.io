문자열 검색 알고리즘

만든 사람의 이름이 Knuth, Morris, Prett 이기에 앞글자를 하나씩 따서 KMP 알고리즘이라 부른다.

 

일반적으로 쉽게 떠올릴 수 있는 슬라이딩 윈도우 방식으로 특정패턴을 찾는 알고리즘을 사용하게 되면

 

전체 텍스트의 길이가 N 이고 패턴의 길이가 M 일때 시간복잡도는 O(NM)이 나오게 된다.

 

이를 더욱 빠르게 찾기 위해 사용되는 알고리즘이 KMP 알고리즘이다. 

KMP 알고리즘의 시간복잡도는 O(N+M) 이다.

 

패턴을 접두사와 접미사로 나눈다.

만약 패턴이 apple 이라고 하자.

그러면 접두사는

a

ap

app

appl

apple

가 되고

접미사는

e

le

ple

pple

apple

가 된다.

 

여기서 pi 배열을 구한다

pi[i] 는 0~i 까지의 부분 문자열에서 접두사와 접미사가 같은 부분 문자열 중에서 가장 긴 것의 길이를 의미한다.

예를 들어 AABAA 라는 문자열이 있다고 하자.

A  => pi[0] = 0

AA => pi[1] = 1

AAB => pi[2] = 0

AABA => pi[3] = 1

AABAA => pi[4] = 2

이런 식으로 pi 배열을 구한다.

 

이 pi 배열을 구했다면

기존의 슬라이딩 윈도우 방식으로 텍스트에서 패턴을 찾다가 패턴이 불일치한 경우 pi 값을 이용하여 패턴이 일정부분 일치했다는 것을 활용하여 중간 비교 과정을 건너뛰는 것이 가능하게 된다.
