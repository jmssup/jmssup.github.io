chomsky hierarchy(촘스키의 분류) 에서 type 2 로 분류되어 있다.

문맥 자유 문법을 표현하는 오토마타이다.

 

유한 상태 기계에 스택이 결합된 것.

스택이 추가되어있어서 기억을 할 수 있다는 점이 특징이다.

이 점을 이용하여 aⁿbⁿ 처럼 앞의 개수와 뒤의 개수가 같은 언어를 표현하는게 가능하다.

 

PDA의 구성요소

  • Q: 상태들의 집합
  • Σ: 입력 알파벳
  • Γ: 스택 알파벳
  • δ: 전이 함수 (좀 복잡함)
  • q₀: 시작 상태
  • Z₀: 초기 스택 심볼
  • F: 종료 상태들의 집합

δ(현재상태, 읽는입력, 스택의상단) = (다음상태, 스택에쓸것)

ex) δ(q1, a, A) = (q2, BA)

→ 상태 q1에서 a를 읽고 스택 위에 A가 있으면, 상태 q2로 가고 스택 위에는 A를 pop하고 대신 B, A를 쌓는다.

 

PDA는 마치 직원이다.

책상 위에 있는 종이 한 장(= 스택의 top)을 보고

눈앞에 고객이 들고 온 서류 한 장(= 입력 문자)을 보고

"아, 이건 이렇게 처리해야겠네" 하고

종이를 넣거나 빼고 다른 책상으로 이동(= 상태 이동)

 

스택에 설정할 기호들은 설계자 본인이 푸시다운오토마타가 잘 돌아가도록 마음대로 설정 가능

ex) aab의 승인 PDA 형상

                                                         𝛿 𝑞0, 𝑎, 𝑧 = 𝑞0, 𝐴𝑧
                                                         𝛿 𝑞3, 𝜆, 𝑧 = 𝑞0, 𝐴𝑧
                                                         𝛿 𝑞0, 𝑎, 𝐴 = 𝑞3, 𝜆
                                                         𝛿 𝑞0, 𝑏, 𝐴 = 𝑞1, 𝜆
                                                         𝛿(𝑞1, 𝜆, 𝑧) = {(𝑞2, 𝜆)}

이러한 전이함수일 때

                                                    (𝑞0, 𝑎𝑎𝑏, 𝑧)┝ (𝑞0, 𝑎𝑏, 𝐴𝑧)
                                                                       ┝ (𝑞3, 𝑏, 𝑧)
                                                                       ┝ (𝑞0, 𝑏, 𝐴𝑧)
                                                                       ┝ (𝑞1, 𝜆, 𝑧)
                                                                       ┝ 𝑞2, 𝜆, 𝜆)

이러한 과정으로 aab가 승인됨.

 

NPDA 비결정적 푸시다운 오토마타

  • 𝑄 : 내부 상태(internal state)의 집합
  • ∑ : 입력기호(input symbol)의 집합, 입력 알파벳
  • Γ : 푸쉬다운 리스트 기호의 집합, 스택 알파벳(stack alphabet)
  • 𝛿 : 𝑄 × (∑ ∪ {𝜆}) × Γ → 2^(𝑄 × (Γ∗)) 전이함수
  • 𝛿의 치역 : 𝑄 × (Γ∗)의 유한 부분 집합만을 포함
  • 𝑞0 ∊ 𝑄 : 초기 상태
  • z ∊ Γ : 스택의 시작 심벌
  • 𝐹 ⊆ 𝑄 : 최종 승인상태들의 집합

 

DPDA

L1 = L2 = 결정적 문맥 자유 언어

L = L1 U L2

하지만 L은 결정적 문맥 자유 언어가 아님

L1 과 L2를 합치면서 하나의 입력심벌과 스택 심벌에 대해서 하나 이상의 전이가 존재할 수 있게 되기 때문이다.
