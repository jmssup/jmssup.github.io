Sun, Mac, 인터넷 : “Big Endian”

LSB가 최대 주소의 위치에 기록된다

 

x86, 안드로이드와 iOS, Windows를 실행하는 ARM프로세서 : “Little Endian”
LSB가 최소 주소의 위치에 기록된다

 

0x01234567 라는 값을 가지는 4바이트의 워드인 변수 x 가 존재할 때 0x100, 0x101, 0x102, 0x103 라는 연속된 4바이트 크기의 주소에 저장한다고 하자.

 

Big Endian에서는 0x100: 0x01 / 0x101: 0x23 / 0x102: 0x45 / 0x103: 0x67

Little Endian 에서는 0x100: 0x67 / 0x101: 0x45 / 0x102: 0x23 / 0x103: 0x01

 

이와 같이 저장한다.

 

C 에서의 비트 연산

비트연산자 &, |, ~, ^

& 비트 단위 and 연산

| 비트 단위 or 연산

~ 비트 단위 not 연산

^ 비트 단위 xor 연산

 

쉬프트 연산
Left Shift: x << y
비트벡터 x 를 왼쪽으로 y 위치만큼 이동
왼쪽에 있던 비트들은 없어지고 오른쪽에는 0으로 채운다

 

Right Shift: x >> y
비트벡터 x 를 오른쪽으로 y 위치 이동
오른쪽에 있던 비트들이 없어진다

 

Right Shift를 진행할때 비트벡터 x를 오른쪽으로 y 위치 이동시키면서 생기는 공백 공간에 0을 채울지 MSB를 복제하는지에 따라서 논리 시프트 산술 시프트로 나뉜다.

 

논리 시프트 (unsigned인 경우 논리시프트로 처리함) 

왼쪽에 0으로 채운다.

 

산술 시프트 (signed인 경우 산술시프트로 처리함)
왼쪽의 가장중요한 비트를 복제한다.

 

Undefined Behavior
시프트의 크기가 음수이거나 워드길이보다 큰 경우

 

Signed와 Unsigned

signed는 부호가 있는 정수, unsigned는 부호가 없는 정수이다.

 

C언어에서는 기본적으로 선언되는 변수들을 signed로 판단하며 unsigned 변수는 unsigned int x; 이런 형식으로 선언해줘야 한다.

 

signed와 unsigned는 MSB의 값을 어떻게 처리하냐가 달라진다.

 

signed는 MSB의 값에 - 를 붙여서 뒤에 나오는 비트들의 값을 더하여 계산하고( 1101 1001 = -39)

unsigned는 MSB를 그대로 더한다. (1101 1001 = 217 )

 

 만약 signed와 unsigned 끼리 비교연산이 일어나는 경우 signed를 unsigned로 implicit 하게 casting하여 처리한다.

 

이로인하여 -1 < 0U로 -1 과 unsigned 0 값을 비교하면 -1이 unsigned로 casting 되면서 -1 < 0U는 False가 되게 된다.
