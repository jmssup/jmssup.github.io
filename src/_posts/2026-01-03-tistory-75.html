Ocaml 에 대한 자료를 보면서 정리했던 내용을 보니 프로그래밍 언어를 구성할 때 필요한 체계를 배우는 것과 동일하다고 판단되어 아래와 같이 정리한다. (AI 한테 물어보거나 따로 검색했던 내용을 다시 AI한테 정리해달라고 한 것임, Ocaml 내용이 좀 들어가 있을 수 있음)


1. 일급 값 (First-class Values)

언어 내에서 함수와 같은 요소가 얼마나 자유로운 권리를 누리는지를 나타내는 개념이다.

  • First-class (1급): 변수에 저장 가능하고, 함수의 인자로 전달할 수 있으며, 함수의 결과로 반환될 수 있는 상태이다. (예: OCaml, JavaScript, Rust의 함수)
  • Second-class (2급): 인자로 넘길 수는 있지만, 함수에서 결과값으로 반환할 수는 없는 제한된 상태이다. (예: 고전 C의 함수)
  • Third-class (3급): 이름만 존재할 뿐, 프로그램 실행 중에 값처럼 주고받는 것이 불가능한 상태이다. (예: 라벨, 예약어)

2. 타입 시스템 (Type System)

데이터의 타입을 검사하는 시점과 그 엄격함에 관한 분류이다.

  • 정적 타이핑 (Static Typing): 컴파일 시점에 모든 타입을 결정한다. 실행 전 오류를 발견할 수 있어 안전하다. (예: OCaml, Rust)
  • 동적 타이핑 (Dynamic Typing): 실행 시점에 타입을 확인한다. 유연하지만 실행 중 타입 에러가 발생할 위험이 있다. (예: Python, JavaScript)
  • 강력한 타입 (Strongly Typed): 타입 간의 암시적 변환을 엄격히 금지한다. (예: OCaml)
  • 약한 타입 (Weakly Typed): 언어가 상황에 맞게 타입을 자동으로 변환하여 연산을 수행한다. (예: JavaScript)

3. 식(Expression)과 문(Statement)

코드가 실행된 후 무엇을 남기는지에 따른 구분이다.

  • 식 (Expression): 계산을 거쳐 반드시 하나의 **값(Value)**을 내놓는 코드이다. OCaml은 거의 모든 것이 식이다.
  • 문 (Statement): 컴퓨터에게 동작을 지시할 뿐, 그 자체가 값을 가지지는 않는 코드이다.
  • 특징: OCaml에서는 if-then-else조차 식이기 때문에 결과값을 반환한다.

4. 커링과 부분 적용 (Currying & Partial Application)

함수가 인자를 처리하는 독특한 논리적 구조이다.

  • 커링 (Currying): 여러 개의 인자를 받는 함수를 인자 하나만 받는 함수들의 연속적인 체인으로 변환하는 것이다.
  • 부분 적용 (Partial Application): 인자를 일부만 전달하여, 남은 인자를 기다리는 새로운 함수를 만들어내는 기법이다.
  • 핵심: OCaml에서 sum x y는 사실 (sum x) y와 같이 순차적으로 계산된다.

5. 동일성 비교 (Equality)

두 데이터가 '같음'을 판별하는 두 가지 기준이다.

  • 구조적 동일성 (Structural Equality): 데이터의 내부 내용물과 구조가 일치하는지 확인한다.
  • 물리적 동일성 (Physical Equality): 두 데이터가 메모리상의 같은 주소를 가리키는 실제 '동일한 물건'인지 확인한다.

6. 셰도잉 (Shadowing)

동일한 이름의 변수를 다시 정의할 때 발생하는 현상이다.

  • 기존 변수의 값을 바꾸는 것이 아니라, 이름이 같은 새로운 변수를 하나 더 만드는 것이다.
  • 기존 변수는 사라지지 않고 새 변수에 의해 잠시 '가려질' 뿐이며, 새 변수의 유효 범위가 끝나면 다시 나타날 수 있다.

7. 와일드카드 (Wildcard, _ )

  • 특정 값이 들어올 자리는 필요하지만, 그 값을 사용할 의사가 없을 때 사용하는 기호이다.
  • 변수 이름이 아니므로 값을 저장할 수 없고, 나중에 불러와서 사용할 수도 없다.
