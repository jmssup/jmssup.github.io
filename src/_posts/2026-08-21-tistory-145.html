현재 진행하는 프로젝트가 x86-64환경에 VMware를 이용하여 진행하는 중이다.

그러나 내 작업환경은 주로 mac이다 보니 gram 노트북에 원격 연결하고 VMware까지 들어가서 진행하는 중인데, 기존에는 gram까지 tailscale과 RustDesk라는 앱을 이용하여 연결하고 VMware를 사용해왔다.

 

그런데 코드를 수정하거나 할 일이 많아져서 VMware내부의 파일에 VSCdoe를 이용해 ssh연결로 접근가능하게 만들고자 한다.

 

기존에 mac에서 gram으로의 연결은 적용되어 있기에 gram에서 vm으로만 연결을 진행해주면 gram 노트북이 중계인 역할로 수행하게하면 된다.

 

먼저 vm ip를 구해준다. ip -br -4 addr 명령어로 vm 내부 ip를 구할 수 있다.

이후 vm 내부에 ssh가없다면 openssh-server를 깔아주고 진행하면 된다.

 

깔려있거나 깔았다면 이제 연결만 진행해주면 된다.

 

이후에 사용한 연결 설정 및 연결 확인용 명령어들

sudo systemctl enable --now ssh / 시작시 ssh 켜지도록 설정

systemctl status ssh --no-pager / ssh 설정 상태 확인

sudo ss -lntp | grep ':22' / 현재 ssh port 연결 상태 확인

Test-NetConnection 192.168.13?.??? -Port 22 / window powershell에서 ssh 포트 연결 확인

 

ssh명령어로 vm까지 연결이 된다면 이제 vscode를 통한 접속도 가능하게 된다.

 

VMware의 내부에 할당하는 ip는 동적으로 재부팅시마다 바뀌기에 설정파일을 이용한 연결 설정을 유지하기 위해 VMware 내부의 ip 할당을 고정할 필요가 있다.

 

고정하는 방법은 VMware의 설정에서 DHCP 범위에 속하지 않는 고정 가능한 ip를 찾고 해당 주소로 VM 내부에서 설정해주면 된다.
