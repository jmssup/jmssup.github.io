그래프의 활용

• 깊이 우선 탐색(DFS)
• 너비 우선 탐색(BFS)
• 연결 성분(Connected Components)
• 이중 연결 성분(Doubly Connected Components)
• 강 연결 성분(Strongly Connected Components)
• 위상 정렬(Topological Sort)
• 최소 신장 트리(minimum Spanning Tree)
• 최단 경로(Shortest Paths)
• 소셜 네트워크 분석(Social network Analysis)

 

그래프 용어

그래프는 정점(Vertex)과 간선(Edge)의 집합으로 간선은 두 정점을 연결하는 선을 의미한다.

그래프는 G=(V, E)로 표현한다. V=정점의 집합, E=간선의집합
• 방향 그래프(Directed Graph): 간선에 방향이 있는 그래프
• 무방향 그래프(Undirected Graph): 간선에 방향이 없는 그래프

 

• 정점 a와 b를 연결하는 간선 (a, b)
• 정점 a에서 b로 방향 있는 간선 <a, b>
• 차수(Degree): 정점에 인접한 정점의 수
• 방향 그래프에서는 차수를 진입 차수(In-degree)와 진출 차수(Out-degree)로 구분한다.

• 그림(a) 정점 a의 차수 = 3, 정점 e의 차수 = 2
• 그림(b) 정점 g의 진입 차수 = 3, 진출 차수 = 1

 

 

• 경로(Path)는 시작점 u부터 도착점 v까지 정점의 나열 - [a, c, b, e]: 정점 a에서 도착점 e까지의 여러 경로 중 하나이다.
• 단순 경로(Simple Path): 경로 상의 정점이 모두 다른 경로
• ‘일반적인’ 경로: 동일한 정점을 중복하여 방문 포함 - [a, b, c, b, e]: 정점 a에서 도착점 e까지의 경로
• 사이클(Cycle): 시작점과 도착점이 동일한 단순 경로 - [a, b, e, d, c, a]

• 연결 성분(Connected Component): 그래프에서 정점들이 서로 연결되어 있는 부분이다.

• 가중치(Weighted) 그래프: 간선에 가중치가 부여된 그래프 - 가중치는 두 점 사이의 거리, 지나는 시간, 음수인 경우도 있다.
• 부분 그래프(Subgraph): 주어진 그래프의 정점과 간선의 일부분(부분 집합)으로 이루어진 그래프 - 부분 그래프는 원래의 그래프에 없는 정점이나 간선을 포함하지 않는다.
• 트리(Tree): 사이클이 없는 그래프
• 신장 트리(Spanning Tree): 주어진 그래프가 하나의 연결 성분으로 구성되어 있을 때, 그래프의 모든 정점들을 사이클 없이 연결하는 부분 그래프

 

그래프 자료구조

• 그래프를 자료구조로서 저장하는 방법
- 인접 행렬(Adjacency Matrix)
- 인접 리스트(Adjacency List)
• n개의 정점을 가진 그래프의 인접 행렬은 2차원 n by n 배열에 저장
• 배열이 a라면, 정점들을 0, 1, 2, · · · , n-1로 하여, 정점 i와 j 사이에 간선이 없으면 a[i][j] = 0, 간선이 있으면 a[i][j] = 1로 표현
• 가중치 그래프는 1 대신 가중치를 저장한다.

• 실세계의 그래프는 대부분 정점의 평균 차수가 작은 희소 그래프(Sparse Graph)이다. 
• 희소 그래프의 간선 수는 최대 간선 수인 n(n-1)/2보다 휠씬 작으므로 인접 리스트에 저장하는 것이 적절하다.

• 조밀 그래프(Dense Graph): 간선의 수가 최대 간선 수에 근접한 그래프이다.
