# 글 카테고리 재분류

2026-10-31 기준 공개 글 139개의 제목·본문·원래 티스토리 분류를 검토했습니다. 사용자가 정한 기준은 **구현·개발 일지는 개발, 개념·설명·사용법은 기술문서**입니다. 글 제목·작성일·본문·이미지·원래 분류·고유 주소는 보존하고 category만 바꿨습니다. 총 102개를 이동했습니다.

## 기준

| 카테고리 | 기준 |
| --- | --- |
| 개발 | 직접 구현한 프로젝트·알고리즘 코드와 구체적인 개발 진행 기록 |
| CTF/Wargame | CTF·워게임의 개별 문제 풀이·풀이 시도와 Fuzzing101 실습 |
| Bug Bounty | 버그 바운티 프로그램 참여·실제 취약점 발견 및 제보 기록 |
| 블로그/기술문서 | 개념·원리 설명, 도구 사용법, 환경 설정, 일반 학습 계획·회고 |
| 논문/컨퍼런스 | 논문 탐색·분석, 명시적인 논문 연구 주제와 학술활동 기록 |
| 공모전/자격증 | 공모전 참가·수상, 자격증 취득·준비 기록 |

CTF라는 단어가 있어도 CTF 플랫폼 개발은 개발입니다. 보안 도구·암호학·취약점 원리만 설명하는 글은 기술문서로 두고, 실제 워게임·실습 문제를 푼 기록과 풀이 시도는 CTF/Wargame으로 분류했습니다. 모각코 글은 본문의 주된 활동으로 판단하여 구현 일지는 개발, 개별 문제 풀이는 CTF, 논문 탐색은 논문/컨퍼런스, 일반 계획·회고는 기술문서로 나눴습니다.

실제 바운티 제보나 자격증·공모전 전용 글은 확인되지 않아 두 카테고리는 비어 있습니다. CVE 번호가 등장한다는 이유만으로 Bug Bounty에 넣지 않았습니다.

## 유지 방법

검토한 글의 최종 분류와 근거는 [categories.json](categories.json)에 기록했습니다. [분류 규칙](../scripts/post-category.mjs)을 이전 도구와 검증 도구가 함께 사용하며, 다시 가져오거나 --refresh를 사용해도 검토한 분류를 적용합니다. 새 글은 직접 category를 지정할 수 있고, 아직 검토하지 않은 티스토리 글만 제목·원래 분류에 대한 보수적인 규칙으로 분류합니다.

검증: Jekyll 빌드와 139개 글의 제목·작성일·본문 해시·이미지·주소·검색 분류 검사를 통과했습니다. 원본 파일 139개도 본문과 category 외 메타데이터를 바이트 단위로 대조했습니다. 별도 캐시 테스트 공간에서 6개 대표 글의 신규 가져오기와 기존 글 재개 시 분류 복원을 확인했으며, 테스트 중 실제 글 본문은 변경하지 않았습니다.
