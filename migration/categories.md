## 유지 관리

`src/_data/categories.json`은 대분류와 하위 목차를 정의합니다. `migration/categories.json`의 글 번호별 분류가 이전 도구의 우선 기준이며, 신규 글은 알려진 원래 분류를 사용합니다. 분류를 판별할 수 없는 신규 글은 자동으로 임의 배치하지 않고 검토를 요청합니다.

CLI의 `ls`, `cd`, `tree`, Tab 자동완성은 하위 경로를 지원합니다. `grep`은 선택한 분류와 모든 하위 분류의 글을 검색합니다. `npm run check`는 139개 글의 분류·본문 보존과 중첩 목차를 함께 검증합니다.
